# 🎨 Пиксельная раскраска — учим таблицу умножения

Веб-приложение «Раскраска по пикселям» (color-by-pixels / pixel math coloring):
ребёнок решает примеры из таблицы умножения и деления, находит ответы на клеточках
картинки и закрашивает их соответствующим цветом.

Чистый HTML + CSS + vanilla JS, без фреймворков и сборки.

## Запуск

**Вариант 1 — просто открыть** `index.html` двойным кликом.
Приложение работает полностью: картинки уже встроены в `js/embedded-art.js`.

**Вариант 2 — локальный сервер** (рекомендуется, если хотите добавлять свои SVG):

```bash
python -m http.server 8000
# или
npx serve .
```

и открыть <http://localhost:8000>. В этом режиме приложение само подхватывает
`assets/manifest.json` и новые SVG из папки `assets/`.

## Как играть

1. Справа — панель цветных кнопок с примерами (например `4 × 8`, `56 ÷ 7`).
   Кнопки идут в случайном порядке — их расположение не подсказывает,
   где на картинке какой цвет.
2. Выбери пример — кнопка выделится.
3. Реши пример и закрашивай клеточки с ответом: кликом или протягиванием
   мышки/пальца. Закрашиваются только клетки «своего» цвета.
4. Когда все клетки цвета закрыты — кнопка получает ✅. Когда закрыты все цвета —
   праздник с конфетти! 🎉

Дополнительно: прогресс-бар, печать чистой раскраски и готового варианта,
сброс, тёмная тема, звук (отключаемый). Прогресс сохраняется в localStorage
и переживает перезагрузку страницы; примеры у каждой картинки свои и
не меняются между сессиями.

## Структура проекта

```
index.html            — разметка приложения
css/style.css         — стили, светлая/тёмная тема, адаптив
js/app.js             — вся логика (канвас, рисование, прогресс, печать)
js/svg-rasterizer.js  — парсер SVG → сетка логических пикселей
js/math-quiz.js       — генератор примеров с уникальными ответами
js/audio.js           — звуковые эффекты (Web Audio API)
js/embedded-art.js    — встроенные копии картинок (генерируется, для file://)
assets/               — SVG-рисунки + manifest.json
tools/generate-assets.mjs — генератор ассетов
```

## Как устроены SVG-рисунки

- Рисунок — сетка «логических пикселей»: обычно 1 клетка = 10×10 пикселей SVG
  (размер клетки определяется автоматически, поддерживается и 20×20 и др.).
- Заливки цветов — обычные `rect`/`path`; **чёрный** (все каналы < 60) считается
  контуром и не раскрашивается; **белый** (все каналы ≥ 246) — фоном.
  Внимание: очень светлые цвета вроде `#fff8e1` остаются раскрашиваемыми,
  а вот чистый `#ffffff` будет считаться фоном — используйте чуть тонированный
  белый (`#fffdf5`).
- До 31 цвета на картинку — по числу различных ответов таблицы умножения 2–9.

## Как добавить свою картинку

1. Положите SVG в папку `assets/`.
2. Добавьте строку в `assets/manifest.json`:

```json
[
  { "file": "моя-картинка.svg", "title": "Моя картинка" }
]
```

3. Если открыто через сервер — картинка сразу появится в выпадающем списке.
   Для работы по file:// запустите `node tools/generate-assets.mjs` — скрипт
   обновит встроенные копии (и заодно сгенерирует рисунки, описанные в нём).

## Печать

- **«Пустая»** — чистая раскраска: контуры, сетка и числа, без заливки.
  Внизу — крупные цветные кнопки с примерами (без ответов — никаких
  подсказок): решил пример → закрасил клетки с ответом этим цветом.
  Кнопки идут в том же перетасованном порядке, что и в приложении.
- **«Готовая»** — полностью закрашенная картинка, кнопки с примерами
  и ответами для самопроверки.

Печать выполняется через скрытый iframe, всплывающие окна не используются.
Посмотреть точный вид печатного документа без диалога печати можно на
служебной странице `tools/print-preview.html` (нужен локальный сервер).
